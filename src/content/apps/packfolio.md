Everyone packs the same eighty percent every time and forgets a different item
each trip. Packfolio keeps a list per trip so the last one is still there to copy
from, and ships templates for the common cases — beach, ski, business, camping,
city break, gym bag.

Items check off as they go in the bag, with a running count so you can tell at a
glance whether you're nearly done. Edit mode allows reordering by dragging, which
matters mainly because people pack in a consistent order.

On-device, no account.
