Forkfolio

A recipe box that fills itself from a link.

About Forkfolio

Recipes on the web arrive wrapped in several hundred words of preamble. Most sites, however, also publish the actual recipe as structured data in the page — so it can simply be read out and kept.

Paste a link and Forkfolio extracts the title, ingredients, steps and image into a draft. The draft is deliberately a review step rather than a silent save, because scraped data is occasionally wrong and it is easier to fix once, up front. Recipes typed by hand work the same way.

Search covers ingredients as well as titles, which is the query you actually have: something with the aubergine before it turns.

Key features

  • Import a recipe by pasting a web link
  • Review and edit the imported draft before it is saved
  • Write your own recipes with ingredients, steps and notes
  • Search across every title and ingredient
  • Tap to check off ingredients while you cook
